# 智选直播 1.0.2 遥控器操作验收

用户最终指定的操作：默认全屏自动播放，菜单隐藏；确认键打开分类和频道；方向键只移动焦点，确认键才切台，切台后菜单保持显示；返回键收起菜单。菜单不显示设置、搜索、诊断、收藏、最近等辅助入口。

程序从已校验的内置目录或本地有效缓存自动播放上次观看的有效频道，首次为 CCTV-1。后台继续下载和校验目录，更新失败使用缓存。打开菜单时定位当前播放频道的分类。客户端选源、缓冲与黑屏恢复、日志记录仍在内部运行。

已先用设备测试复现原界面不符合上述交互，再修改并验证。Python 全量160项、Android JVM 27项、Android TV 12项设备回归通过；最终分类定位小改后再跑4项菜单设备测试、构建和静态检查。

仍使用14台37入口快照，数据内容摘要 `cf70074950f8ed63328a943c9d2bfc095bfd0a251095b87a253a5ac1291296f0`。CCTV-1/8当前720P，其余12台测得1080P。真实移动宽带电视的长时流畅度待用户验收，公共上游变化无法由客户端保证消除。
