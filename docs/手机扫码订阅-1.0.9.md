# 1.0.9 手机扫码添加订阅

## 电视上怎么用

1. 覆盖安装1.0.9，不必卸载旧版。
2. 按遥控器确定键打开频道侧栏，选择底部“订阅设置”。遥控器有菜单键时也可直接按菜单键进入。
3. 手机和电视连接同一路由器，用相机或浏览器扫码。打开后在手机输入直播订阅地址，点击“发送并加载到电视”。如果扫码工具拦截局域网页面，在手机浏览器输入电视显示的完整地址。
4. 电视下载并校验成功后保存订阅、加载频道，并播放第一台；手机会显示加载频道数。按电视返回键回到频道列表，再按返回键收起列表。
5. 订阅会保存，重启继续使用；设置里可以刷新、手动输入地址或恢复默认订阅。

手机推送通过局域网直接到电视，不经过GitHub，不需要VPN。访客Wi-Fi、AP隔离或不同路由器可能阻止手机访问电视。请保持电视设置页面打开，退出设置或应用进入后台后，本次二维码失效，重新进入设置生成新二维码。

## 支持范围

- UTF-8 M3U / M3U8频道列表，支持EXTINF频道名、group-title、EXTGRP和相对播放地址。
- 本项目schemaVersion=1的JSON目录，保留完整性校验。
- 订阅和媒体地址支持HTTP/HTTPS；相同分组和名称的多个地址合并为主备来源；不加载logo。
- 仅接受可直接请求的地址，不解析第三方私有配置格式，也未实现EXTVLCOPT自定义请求头。
- 单个频道的HLS分片清单不属于频道订阅，会提示输入频道列表。
- 下载失败、空列表或格式错误不覆盖当前订阅和频道。成功导入会替换当前频道列表，可恢复默认订阅。

导入只表示列表可解析，不表示里面每条直播线路已验证流畅。本功能方便用户把同一订阅用于其他播放器和本客户端做对照。

## 实现和验证

- 保留单播放器和现有OK选台、返回收起菜单行为，只增加订阅设置入口。
- 设置页面内启动局域网输入服务，随机端口和随机会话地址，不创建云端推送服务。
- 校验成功后才保存；本地缓存使重启或订阅服务器临时不可达时仍可恢复上次有效列表。
- 单元测试覆盖M3U解析、同频道主备合并、相对地址、拒绝单台分片清单、随机会话验证和手机表单编码。
- Android模拟器测试解码真实二维码，访问手机输入网页、提交本地M3U订阅、验证视频实际出帧，确认错误订阅不覆盖、重启保留订阅。
- 二维码使用ZXing Core 3.5.3生成。实体TCL电视和用户手机扫码结果仍需实测。
