# 电视直播选台界面与实播交付计划

目标：按用户明确指定的成熟电视直播操作方式，左侧分类、相邻频道子菜单、右侧保留画面；用遥控器选台，提供央视一至十套和四个卫视的实播目录。

架构：沿用单个 Media3 播放器，频道菜单改为左侧覆盖面板，设置、搜索、诊断作为次级界面。公开候选试播目录独立发布，不伪造正式分发授权。

技术：Kotlin Views、Android TV 遥控器、现有 Python 探测器。

约束：中文文档；不增加播放器实例；不丢失收藏、最近观看、搜索、缓存和自动切源；不将本机短测说成电视长时验证。

## 验证重点

频道背景更新不能抢走分类焦点；地方台只包含用户指定卫视；同一播放器切台；空目录仍可进入设置；菜单收起后上下换台及 OK 重开可用。
