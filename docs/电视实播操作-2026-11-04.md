# 央视与地方卫视电视实播

本轮范围：CCTV-1 至 CCTV-10，以及湖南卫视、江苏卫视、浙江卫视、北京卫视。不加入港澳台或国外频道。用户当前电视为移动宽带。

## 安装后怎么操作

1. 覆盖安装智选直播 1.0.1，应用包名和调试签名沿用上一版，无需先卸载。
2. 打开应用，内置目录和稳定优先策略自动生效。旧版默认空目录地址自动迁移，无需手输地址或进入设置。
3. 左侧选“央视”，按右键进入频道子菜单，上下选择 CCTV-1，按 OK 播放；再次按 OK 打开菜单。选择“地方台”测试四个指定卫视。

频道目录：https://luolihao-aicode.github.io/tvbox-githublink/tv-test.json 。普通播放器使用同一站点的 `tv-test.m3u`。新版内置首版目录快照，后台自动检查更新。客户界面只显示分类、频道与播放画面，没有设置、搜索、诊断、收藏或最近观看入口。

## 测什么

先每台观看约一分钟，记录能否出现画面、台名是否正确、清晰度和缓冲。再选两三个常看频道连续观看十分钟。问题反馈至少包含台名、发生时间、等待多久、有声音还是完全黑屏。画面正常不需要进入诊断。

日志自动位于 `/sdcard/Android/data/com.luolihao.smarttv/files/Documents/diagnostics/`，记录首帧、播放异常和切源原因，观看记录不上传。客户无需操作诊断按钮；需要排查时由开发人员协助取出文件。

## 两端各自负责什么

GitHub 收集并准确匹配同台多条候选，检查清单、分片、视频/音频解码参数，生成带版本及完整性校验的多源 JSON。试播目录独立每日北京时间 04:07 检测；零合格或覆盖下降时保留旧有效文件。GitHub 定时任务可能延迟，不承担视频转发。

电视端读取与缓存 JSON，按本机网络的历史成功、卡顿和失败记录选源。只有声音、无首帧、进度停滞或持续缓冲触发有限重试、重建和切备；60 秒内三次采样到缓冲直接切备。保持单个播放器，备用预检仅 HTTP HEAD，不属于预解码或无缝拼接。

国内移动宽带和海外网络各自积累本地记录，不能用一个 GitHub 检测点保证全球质量；首版未部署多地区持续测量。公开来源的短时采样也不能保证长期稳定。分辨率尺寸不等于节目真实清晰细节，需要电视实看验收。

试播来源的节目分发授权未确认，不将其加入正式授权目录，不把候选源的公开性当成授权证明。
